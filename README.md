# Hola Mundo en Unity

Primer proyecto realizado en Unity para la asignatura Diseño de Juegos II.

## Objetivo

Crear un script en C# que imprima el mensaje "Hola mundo".

## Script

El archivo principal se encuentra en:

Assets/Scripts/HolaMundo.cs

## Funcionamiento

El script utiliza `Debug.Log("Hola mundo");` dentro del método `Start()` para mostrar el mensaje en la consola de Unity.
